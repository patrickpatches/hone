"What you have" — pill cloud → organised list

Everything in the current pantry stays: the search, the "recipes you can cook now" banner, the match carousel. The single change is the box that holds your stocked ingredients — from a wrapping cloud of pills to a tidy, collapsible, category-grouped list with the line icons. Plus a +/− stepper so you set "3 tomatoes" without typing it three times.

One change, three details: (1) grouped by category with collapsible sections + the SVG icons; (2) each row shows name, the amount you have, and which planned recipe uses it; (3) a +/− stepper to add multiples in one go. Nothing else on the screen moves.

The cool bit

Add multiples with a stepper

Type once, step the count

Search "tomato" once. Instead of adding it three separate times, tap + to set how many you've got. The row commits the quantity in one move — and the same stepper lives on the list row, so you can adjust later without re-searching.
